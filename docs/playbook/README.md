# Studio playbook

The research playbook is available at `/playbook` for people with the direct URL. It is intentionally absent from navigation and has `noindex, nofollow` metadata.

The route is `src/app/(site)/playbook/page.tsx`, its interactive content is in `src/components/playbook/`, and the competitor screenshots it displays are in `public/research/shots/`. Written research notes remain in `research/`.
